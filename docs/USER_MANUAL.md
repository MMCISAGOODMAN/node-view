# NodeView 用户使用手册

## 一、界面概览

```
┌─────────────────────────────────────────────────────────┐
│  NodeView  │  打开  保存  │  JSON  格式化  压缩  │  主题  │
├─────────────────────────────────────────────────────────┤
│  搜索节点…                                          ⌘F  │
├──────────────────┬──────────────────────────────────────┤
│  结构            │  编辑器                               │
│  (左侧 ~45%)     │  (CodeMirror 6)                       │
├──────────────────┴──────────────────────────────────────┤
│  状态栏：就绪 | JSONPath | 节点数 | 层级 | 大小 | 格式   │
└─────────────────────────────────────────────────────────┘
```

## 二、基本操作

### 2.1 打开文件

1. 点击工具栏 **打开**，或使用菜单 **File → Open...**
2. 快捷键：`Ctrl+O`（Mac: `Cmd+O`）
3. 选择 `.json`、`.yaml` 或 `.yml` 文件
4. 内容自动加载到编辑器和树形视图

### 2.2 保存文件

| 操作 | 方式 |
|------|------|
| 保存 | `Ctrl+S` / `Cmd+S`，或工具栏 **保存**，或 **File → Save** |
| 另存为 | `Ctrl+Shift+S` / `Cmd+Shift+S`，或 **File → Save As...** |

首次保存会弹出路径选择对话框；已有文件路径时直接覆盖。

### 2.3 编辑数据

#### 代码编辑器（右侧）

- 直接修改 JSON / YAML 文本
- 左侧树在约 300ms 后自动刷新
- 语法错误以红色波浪线标注，状态栏显示错误详情

#### 树形视图（左侧）

| 操作 | 效果 |
|------|------|
| 单击节点 | 选中，代码编辑器滚动到对应行 |
| 双击叶子节点 | 进入内联编辑 |
| 右键叶子节点 | 同双击，进入编辑 |
| 点击展开箭头 | 展开 / 折叠子节点 |
| 悬停 → 复制按钮 | 复制该节点 JSONPath |

编辑时按 `Enter` 确认，`Esc` 取消。

> 对象 `{}` 和数组 `[]` 节点暂不支持在树中直接编辑，请在代码编辑器中修改。

## 三、格式操作

| 按钮 | 功能 |
|------|------|
| **JSON / YAML** | 在当前格式间无损切换 |
| **格式化** | 2 空格缩进美化排版 |
| **压缩** | 去除换行，压缩为单行 |

## 四、搜索

1. 点击搜索框，或按 `Ctrl+F` / `Cmd+F`
2. 输入关键词，匹配节点高亮，不匹配的节点隐藏
3. 点击清除按钮或清空输入框恢复全部节点

## 五、JSONPath 复制

1. 鼠标悬停在节点上
2. 点击右侧 **复制** 图标
3. JSONPath（如 `$.config.theme`）写入剪贴板
4. 底部弹出确认提示

## 六、主题

点击工具栏主题图标切换暗色 / 亮色。默认暗色（VS Code 风格）。

## 七、面板调整

拖动中间分隔条调整左右宽度，范围 20% ~ 70%，默认左侧 45%。

## 八、状态栏

| 区域 | 内容 |
|------|------|
| 左侧 | 状态圆点 + 就绪 / 已修改 / 错误信息 |
| 中间 | 当前选中节点的 JSONPath |
| 右侧 | 节点总数、最大层级、数据大小、当前格式 |

状态圆点颜色：绿色 = 就绪，黄色 = 已修改，红色 = 解析错误。

## 九、自动保存

每次修改后自动保存到 localStorage。下次启动时恢复上次内容；若无缓存则加载内置示例数据。

## 十、类型徽章

| 快捷键 | 功能 |

| `Ctrl/Cmd + O` | 打开文件 |
| `Ctrl/Cmd + S` | 保存 |

## 十二、常见问题

**Q: 修改代码后树没有更新？**
A: 有 300ms 防抖延迟。若 JSON/YAML 存在语法错误，树保持上次成功解析的结果，修复错误后即可刷新。

**Q: JSON 支持注释吗？**
A: 支持。使用 JSON5 解析，兼容 `//`、`/* */` 注释和尾逗号。

**Q: 如何处理大文件？**
A: 树只渲染已展开的可见节点。超大文件（>10MB）建议直接在代码编辑器中操作。

**Q: 在哪里下载安装包？**
A: 前往 [GitHub Releases](https://github.com/MMCISAGOODMAN/node-view/releases) 下载对应系统版本。
